</p>

---

## About

My phone automatically disables Wireless Debugging all the time, and I use it a lot with Android Studio. So I made this quick settings tile to make it easier to toggle on the go.

## Installation

1. Download the `app-debug.apk` from [Releases](https://github.com/IdleBuilt/WiBuggy/releases).
2. Open the APK on your device.
3. When prompted, enable **"Install from unknown sources"** for your browser or file manager.
4. Done — the tile will appear in your quick settings panel.

> **Note:** Android may warn that this app is dangerous. That's expected — the APK is unsigned and not distributed through Google Play. It's perfectly safe.

## Why isn't this on Google Play?

Google requires a $25 developer account to publish apps. My country doesn't allow me to pay for one, so the Play Store isn't an option. This is the best I can do.
